Assignment 1 — Bubble Sort

Sort Student Marks in Ascending Order

Problem:
Given student marks, sort them from lowest to highest using Bubble Sort.
Sample Input:
[72, 45, 88, 61, 39]
Task:
Write Bubble Sort manually. Do not use sort() or sorted().
Expected Output:
[39, 45, 61, 72, 88]
Compare adjacent values and swap when the left value is greater than the right value.
marks = [72, 45, 88, 61, 39] for i in range(len(marks) - 1): for j in range(len(marks) - 1 - i): if marks[j] > marks[j + 1]: marks[j], marks[j + 1] = marks[j + 1], marks[j] print(marks)

Use Bubble Sort to arrange prices from highest to lowest.

[2499, 1299, 999, 799, 499]

prices = [499, 1299, 799, 2499, 999] for i in range(len(prices) - 1): for j in range(len(prices) - 1 - i): if prices[j] < prices[j + 1]: prices[j], prices[j + 1] = prices[j + 1], prices[j] print(prices)
Assignment 3 — Bubble Sort

Optimized Bubble Sort with Early Stop

Problem:
A list may already be sorted. Avoid unnecessary passes.
Sample Input:
[10, 20, 30, 40, 50]
Task:
Add a swapped flag and stop when no swap occurs.
Expected Output:
[10, 20, 30, 40, 50]
Set swapped = False at the start of each pass.
data = [10, 20, 30, 40, 50] for i in range(len(data) - 1): swapped = False for j in range(len(data) - 1 - i): if data[j] > data[j + 1]: data[j], data[j + 1] = data[j + 1], data[j] swapped = True if not swapped: break print(data)
Assignment 4 — Selection Sort

Sort Employee Salaries

Problem:
HR wants salary values arranged from lowest to highest.
Sample Input:
[42000, 28000, 55000, 31000, 47000]
Task:
Use Selection Sort and track the minimum index.
Expected Output:
[28000, 31000, 42000, 47000, 55000]
For every pass, start with min_index = i.
salary = [42000, 28000, 55000, 31000, 47000] for i in range(len(salary) - 1): min_index = i for j in range(i + 1, len(salary)): if salary[j] < salary[min_index]: min_index = j salary[i], salary[min_index] = salary[min_index], salary[i] print(salary)

scores = [150, 320, 210, 450, 275] for i in range(len(scores) - 1): max_index = i for j in range(i + 1, len(scores)): if scores[j] > scores[max_index]: max_index = j scores[i], scores[max_index] = scores[max_index], scores[i] print(scores)
Assignment 6 — Selection Sort

Count the Number of Swaps

Problem:
You want to understand how many swaps Selection Sort performs.
Sample Input:
[64, 25, 12, 22, 11]
Task:
Sort the list and also print the total number of actual swaps.
Expected Sorted Output:
[11, 12, 22, 25, 64]
Increase the counter only when min_index != i.
data = [64, 25, 12, 22, 11] swap_count = 0 for i in range(len(data) - 1): min_index = i for j in range(i + 1, len(data)): if data[j] < data[min_index]: min_index = j if min_index != i: data[i], data[min_index] = data[min_index], data[i] swap_count += 1 print("Sorted:", data) print("Swaps:", swap_count)
Assignment 7 — Insertion Sort

Sort Student Ages

Problem:
Arrange student ages from youngest to oldest.
Sample Input:
[22, 18, 25, 19, 21]
Task:
Use Insertion Sort with key and shifting.
Expected Output:
[18, 19, 21, 22, 25]
Store the current element in key before shifting values.
ages = [22, 18, 25, 19, 21] for i in range(1, len(ages)): key = ages[i] j = i - 1 while j >= 0 and ages[j] > key: ages[j + 1] = ages[j] j -= 1 ages[j + 1] = key print(ages)
Assignment 8 — Insertion Sort

Sort Delivery Times

Problem:
A logistics system wants shorter delivery times first.
Sample Input:
[42, 18, 35, 27, 50, 22]
Task:
Sort delivery times using Insertion Sort.
Expected Output:
[18, 22, 27, 35, 42, 50]
Move every value greater than the key one position to the right.
times = [42, 18, 35, 27, 50, 22] for i in range(1, len(times)): key = times[i] j = i - 1 while j >= 0 and times[j] > key: times[j + 1] = times[j] j -= 1 times[j + 1] = key print(times)
Assignment 9 — Insertion Sort

Descending Insertion Sort

Problem:
Arrange sales values from highest to lowest.
Sample Input:
[1200, 900, 1500, 700, 1300]
Task:
Modify Insertion Sort for descending order.
Expected Output:
[1500, 1300, 1200, 900, 700]
For descending order, shift while the left value is smaller than the key.
sales = [1200, 900, 1500, 700, 1300] for i in range(1, len(sales)): key = sales[i] j = i - 1 while j >= 0 and sales[j] < key: sales[j + 1] = sales[j] j -= 1 sales[j + 1] = key print(sales)
